# Sales Folders and Car Identities Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fixed looks for the five Voltrieve cars with reference images, and 23 dealership-style sales PDFs generated from `data/voltrieve.yaml`, indexed in place of today's brochures and spec sheets.

**Architecture:** Facts live in `data/voltrieve.yaml`; image prompt text lives in `data/design/cars.yaml`. The generator renders Markdown from Jinja2 templates, then HTML with a shared stylesheet, then PDF through headless Chromium. Images are generated by a rerunnable command that calls `ailloy image`, editing from per-car studio masters. Uploading prunes blobs that are no longer in the manifest.

**Tech Stack:** Python 3.12+, uv, pydantic, Jinja2, markdown-it-py, Playwright (Chromium), Pillow, pypdf, pytest; `ailloy` CLI with `gpt-image-2.5-flare`; Azure AI Search, Blob Storage.

**Spec:** `docs/superpowers/specs/2026-11-10-sales-folders-design.md`

## Global Constraints

- No em-dash (U+2014) in any file, document, prompt, commit message or comment.
- No real car brand names, logos or recognizable real designs in prompts or images. The Fjord rear has no vertical pillar lights.
- Every number in a document comes from `data/voltrieve.yaml`; nothing numeric is typed into a template.
- Prices: Pure = today's `price` per model; Plus = Pure x 1.08 and Prime = Pure x 1.16, rounded to the nearest 1,000 SEK and 100 EUR. The AWD surcharge is unchanged.
- Color prices: hero color 0; solid 0; metallic and pearl 9,900 SEK / 900 EUR; satin 14,900 SEK / 1,350 EUR.
- Brochures and specification sheets contain no prices. Price lists and the buyer's guide do.
- `get_prices` and the dealer service do not change.
- Euro NCAP, crash test, factory and production stay in `not_documented`; warranty is removed from it.
- Images: 1536 x 1024 masters as PNG, document copies as WebP 1600 px wide.
- Image budget: hard ceiling 40 USD including retries. Only the 10 masters may be generated before the user approves the measured cost.
- Work stops for the user at the two STOP points below. Do not continue past a STOP without the user's answer.
- Commit or push only when the user asks; work on a branch.

## Review Focus

1. A car regenerated later must still match its master: the prompt for every shot repeats the car's full identity text. Test: every built prompt contains the car's plate, front signature and wheel description.
2. Rerunning the image command must never pay twice: existing files are skipped. Test: a run with all files present makes zero `ailloy` calls.
3. A color or wheel key in a trim or in `cars.yaml` that does not exist in the catalog must fail loading, not render "None". Test in Task 3.
4. Price tables must survive PDF text extraction with rows intact (each row's trim, drive and price on one line). Test in Task 5.
5. Pruning must never delete a blob that is in the manifest, and must list before deleting. Test in Task 7.

**Interfaces:**

- Monthly payment is an annuity with a balloon: `r = nominal_rate / 12`, `loan = price - deposit`, `monthly = (loan - residual / (1 + r) ** months) * r / (1 - (1 + r) ** -months) + monthly_admin_fee`, rounded to whole currency units.
